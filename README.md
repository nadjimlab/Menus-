# CHENEB TACOS 🌮 - Menu Digital & Commande en Ligne

تطبيق وموقع القائمة الرقمية التفاعلية ونظام الطلب المباشر لمطعم **CHENEB TACOS** (حي الرمال - الوادي).

## الميزات الرئيسية
- 📋 قائمة طعام رقمية تفاعلية مع أسعار وتفاصيل دقيقة لكل حجم وصلصة وإضافات.
- 🍽️ نظام الطلب المباشر من الطاولة (مع دعم مسح QR Code لكل طاولة).
- 🛵 نظام الطلب أونلاين (توصيل للمنزل أو استلام من المحل).
- 💬 إرسال الطلبات فوري ومؤتمت عبر واتساب إلى رقم المطعم.
- 🔒 لوحة تتبع وإدارة الطلبات (KDS) محمية برمز سري PIN.

## النشر التلقائي على GitHub Pages
تم إعداد المشروع مسبقاً ليعمل مباشرة وبشكل تلقائي على **GitHub Pages**:
1. تم ضبط المسارات النسبية في `vite.config.ts` (`base: './'`).
2. تم إضافة ملف سير العمل التلقائي `.github/workflows/deploy.yml` (GitHub Actions).

### خطوات تفعيل الاستضافة على GitHub Pages:
1. من صفحة المستودع على GitHub، انتقل إلى **Settings** (الإعدادات).
2. في القائمة الجانبية اختر **Pages**.
3. تحت قسم **Build and deployment**:
   - في خانة **Source**، اختر **GitHub Actions**.
4. سيقوم GitHub تلقائياً ببناء الموقع ونشره خلال دقيقة واحدة، وسيظهر لك رابط موقعك المباشر:
   `https://<your-username>.github.io/<repo-name>/`
